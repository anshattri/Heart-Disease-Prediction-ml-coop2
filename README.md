# Heart Disease Prediction using Machine Learning

## 📌 Overview
This project focuses on predicting heart disease using supervised machine learning algorithms. The goal is to assist in early diagnosis and improve healthcare decision-making.

## 🎯 Objective
- Predict presence of heart disease
- Compare performance of ML models
- Identify best performing algorithm

## 📊 Dataset
- UCI Heart Disease Dataset
- Features include age, cholesterol, blood pressure, etc.

## ⚙️ Algorithms Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

## 📈 Results
- Logistic Regression: 82%
- KNN: 80%
- Decision Tree: 84%
- Random Forest: 89% (Best)

## 🧠 Conclusion
Random Forest performed best and can be used for accurate prediction of heart disease.
